# CV de Awa Sylla

Bienvenue sur mon CV interactif en ligne, développé avec **HTML** et **Tailwind CSS** .

## À propos

Je suis **développeuse fullstack** passionnée par le design et les interfaces élégantes. Ce projet met en avant mon profil, mes compétences, mes projets et mes coordonnées de manière responsive.

## Technologies utilisées

- HTML5
- Tailwind CSS
- Font Awesome (pour les icônes)


## 📱 Responsive Design

Le site est **100% responsive**, compatible avec tous les appareils (mobile, tablette, desktop). Optimisé pour une bonne expérience utilisateur sur tous les supports.

## 💡 Fonctionnalités

- ✅ Présentation animée
- ✅ Section "À propos de moi"
- ✅ Liste de compétences avec barres de progression
- ✅ Expériences
- ✅ Section Contact avec icônes et liens sociaux
